# Contributing to JDRAID

Thank you for your interest in contributing to JDRAID! We welcome all contributions.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/JDRAID.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Install dependencies: `npm install`
5. Set up your `.env` file using `.env.example`

## Development Guidelines

### Code Style
- Use meaningful variable and function names
- Comment complex logic
- Follow existing code patterns
- Use 2-space indentation

### Commit Messages
- Use clear, descriptive commit messages
- Start with a verb (Add, Fix, Update, etc.)
- Keep messages concise

Examples:
```
Add hero rating filter endpoint
Fix account update bug
Update API documentation
```

### Testing
- Write tests for new features
- Ensure all tests pass before submitting PR
- Test both positive and negative cases

## Pull Request Process

1. Update your branch: `git fetch origin` and `git rebase origin/main`
2. Push to your fork: `git push origin feature/your-feature-name`
3. Open a Pull Request with clear title and description
4. Address feedback from reviewers
5. Ensure all CI checks pass

## Bug Reports

When reporting bugs, include:
- Clear description of the issue
- Steps to reproduce
- Expected behavior
- Actual behavior
- Your environment (OS, Node version, etc.)

## Feature Requests

- Describe the feature clearly
- Explain why it's needed
- Provide examples of how it would be used
